# «Кибер-крылья» — программирование «Пионера Мини 2»

Учебный комплект команды для 11 заданий финала. Для № 1, 2, 8 и 9 есть программы только с командами высокого уровня SDK 2. № 10 и 11 читают телеметрию. Для № 3–7 полный сценарий работает в MuJoCo с камерой на модели. Управление реальным дроном по изображению для этих пяти заданий ещё предстоит реализовать. Испытания на выданном борту остаются открытыми.

Регламент, п. 8.2.5, запрещает использовать ИИ для выполнения зачётных заданий и разрешает методические материалы и официальную документацию. Допуск заранее подготовленных файлов команда уточняет у эксперта. [Регламент](Регламент_финальный_этап_КИБЕР_КРЫЛЬЯ.pdf) · [Методичка по SDK 2](<Методичка_Pioneer_Mini_2_pioneer_sdk2 (2).pdf>)

## Как начать на ноутбуке

На подготовленном ноутбуке откройте PowerShell в папке проекта и сразу переходите к проверке ниже. На новом компьютере нужен 64-битный Python 3.12 для Windows. Заранее скачайте репозиторий через **Code → Download ZIP** и распакуйте его либо выполните `git clone https://github.com/levbrain404missing-del/OceanikaSim.git`. Для скачивания приватного репозитория нужен GitHub-аккаунт с доступом. Откройте PowerShell в папке, где лежит этот README, и один раз установите зависимости, пока есть интернет.

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Полная проверка без дрона** работает локально. Команда запускает все тесты, проверяет зависимости и обновляет отчёт по каждому номеру. В конце ожидайте строку «Пройдено» и код выхода 0. При ошибке откройте отчёт и найдите имя упавшего теста в диагностике.

```powershell
$py = '.\.venv\Scripts\python.exe'
& $py -X utf8 -B 'Тренировка/check_home.py'
```

## Как открыть своё задание

В таблице приведены команды для PowerShell из корня проекта, после строки `$py = '.\.venv\Scripts\python.exe'`. Размеры в геометрических сценариях задаются в метрах, входные углы — в градусах. Параметры примеров относятся к учебной площадке.

| № | Задание | Команда для домашней проверки |
|---|---|---|
| 1 | Круг XZ радиусом 0,6 м | `& $py Тренировка/geometry_missions.py circle 0.6 --height 1.5` |
| 2 | Восьмёрка XZ | `& $py Тренировка/geometry_missions.py eight --height 1.5` |
| 3 | Яркая посадочная зона | `& $py Тренировка/visual_mujoco.py 3 --seed 7` |
| 4 | Замкнутая линия до сигнала остановки | `& $py Тренировка/visual_mujoco.py 4 --stop-after 19` |
| 5 | Повороты по ArUco и финиш | `& $py Тренировка/visual_mujoco.py 5` |
| 6 | Цветные ворота | `& $py Тренировка/visual_mujoco.py 6 --color blue` |
| 7 | Посадка на выбранный ID | `& $py Тренировка/visual_mujoco.py 7 --id 7` |
| 8 | Кратчайший маршрут | `& $py Тренировка/shortest_route.py` — введите старт XY, число точек и координаты. Прогон с моделью — `& $py Тренировка/physics_bench.py route` |
| 9 | Сферические координаты и зависание | `& $py Тренировка/geometry_missions.py spherical 2 45 30 --height 1.5` |
| 10 | Два запроса телеметрии | `& $py -m unittest discover -s Тренировка -k telemetry_terminal` |
| 11 | Карта движения и след | `& $py -m unittest discover -s Тренировка -k map_window` |

**Контрольный пример для № 8.** Старт `0 0`, число точек `3`, затем по строке `1 0`, `1 1`, `0 1`. Ожидаемая длина с возвратом — 4 м. Направление обхода может быть обратным при той же длине.

**Режим оборудования.** При разрешённом инструктором испытании № 1, 2 и 9 переключаются с MuJoCo на борт параметром `--fly`. Для № 8 полётный режим включается парой параметров `--fly-at Z` и `--point-timeout SEC`, где Z — согласованная локальная высотная отметка в метрах, SEC — время подтверждения точки в секундах. В этом режиме скрипт берёт координаты старта из SDK. Команды подключения выполняются в окружении с доступом к бортовому сервису Pioneer. Для № 3–7 в комплекте предусмотрен только учебный полёт в симуляторе.

## Профиль камеры и показания борта

До любых полётных испытаний проверьте профиль **в том окружении Python, где будет работать программа**. На подготовленном Windows-ноутбуке профиль установленного пакета — `PizeroSwarm`. Команда `sdk_profile.py` читает локальную конфигурацию SDK. На выданном борту этот же файл покажет его профиль. [Подготовка стенда, параметры режимов и границы проверок](<Тренировка/Домашние стенды.md>)

```powershell
& $py Тренировка/sdk_profile.py
```

В окружении с подключённым SDK команда `monitor.py telemetry` запрашивает новые данные после каждого Enter, а `q` завершает работу. Для `monitor.py map` задайте границы xmin, xmax, ymin, ymax в метрах и масштаб в пикселях на метр. Окно карты закрывается клавишей Esc или q. Для разбора изображения на земле `camera_capture.py` сохраняет исходный кадр в новую папку. Пример команды для снимка — `& $py Тренировка/camera_capture.py кадры-01 --count 1`. [Примеры чтения камеры и телеметрии от производителя](<Тренировка/Геоскан — примеры камеры и телеметрии 9fb34de.zip>)
